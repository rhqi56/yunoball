1. System Overview

The JapanTrip2026 Live Monitoring System ("the System") is a network-based video surveillance and monitoring platform developed for educational and authorized security purposes. Access to this System is strictly controlled and logged.

⚠ This system is protected under Republic Act No. 10173 — Data Privacy Act of 2012 (Philippines) and applicable international data protection regulations.

2. Authorized Use Only

Access to this System is restricted to authorized personnel only. By proceeding past this notice, you confirm that:

  • You are an authorized user with valid credentials issued by the System Administrator.
  • You will not attempt to gain unauthorized access to any feature, camera feed, or administrative function.
  • You will not share your credentials with any third party.
  • You will not use this system for any purpose outside of its intended use.

3. Camera & Video Data

This System may access and display live video feeds from connected IP cameras and network surveillance devices. The following terms apply to all video data:

  • All camera feeds are processed in real-time and are not permanently stored by default.
  • Snapshots taken through this System are saved locally to the authorized user's device only.
  • Camera feeds must only be accessed in environments where surveillance is legally permitted.
  • Users must not record, redistribute, or publish any video data captured through this System.

4. Security & Access Monitoring

For security purposes, this System actively monitors all login attempts. The following measures are enforced:

  • All failed login attempts are logged and flagged to System Administrators in real time.
  • Accounts are temporarily suspended after 3 consecutive failed login attempts.
  • Suspicious access patterns may result in permanent access revocation.
  • IP addresses and session timestamps may be recorded for audit purposes.

5. Data Privacy

The System Administrator is responsible for ensuring compliance with applicable data privacy laws. Users acknowledge that:

  • Session activity within this system may be logged for security audit purposes.
  • No personal data collected through this system shall be shared with unauthorized parties.
  • Users have the right to request a copy of any data collected about their session by contacting the System Administrator.

6. Prohibited Activities

The following activities are strictly prohibited and may result in legal action:

  • Attempting to bypass the authentication system or lockout mechanisms.
  • Accessing camera feeds of areas where surveillance is not authorized.
  • Tampering with or disabling any security feature of this System.
  • Using this System to harass, monitor, or surveil individuals without consent.

7. Disclaimer of Liability
